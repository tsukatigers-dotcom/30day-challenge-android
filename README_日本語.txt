# 30日間パフォーマンス強化（Android向けPWA）

## 内容
- 30日間の段階的な運動メニュー
- 今日のチェックリストと達成率
- 体重、睡眠、性欲、勃起状態、射精後の回復時間などの任意記録
- JSON形式のバックアップ・復元
- 初回アクセス後のオフライン利用（ブラウザの対応状況による）

## Androidにインストールする方法
このフォルダの中身を、HTTPS対応のWebサーバーにアップロードしてください。
GitHub Pagesなどの静的ホスティングが利用できます。
アップロード後、AndroidのChromeで公開URLを開き、
右上の「︙」→「アプリをインストール」または「ホーム画面に追加」→「インストール」を選んでください。

※ ZIPをそのままAndroidに入れるだけではPWAとしてインストールできません。
※ この成果物はAPKではありません。Google Playストアへの公開も行っていません。
※ アプリ内の記録はブラウザのlocalStorageに保存されます。ブラウザデータ消去や端末変更に備えて、定期的にJSONを書き出してください。
※ 性機能に関する記録はプライベート情報です。端末ロックを使用し、共有端末では記録を残さないでください。
